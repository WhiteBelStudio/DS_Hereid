# HeradeLegend — Pterodactyl startup

## Runtime
- Egg: Node.js 22
- Install command: npm install
- Startup command (for a Git clone of this repository):
  git pull --ff-only origin main && npm install --omit=dev && npm start

## Required environment variables
- DISCORD_TOKEN — Discord bot token
- CLIENT_ID — Discord application ID
- GUILD_ID — test/target Discord server ID

## Recommended environment variables
- DATABASE_PATH=./data/bot.sqlite
- LOG_LEVEL=info
- BOT_OWNER_IDS=comma-separated Discord user IDs

## First deployment
1. Clone this repository into the Pterodactyl server directory. The directory must contain the .git folder.
2. Select the Node.js 22 egg.
3. Set the required environment variables in Pterodactyl's Startup/Variables panel. Do not put tokens in source files.
4. Run the install command once: npm install.
5. Set the startup command shown above. It fetches the latest main branch with a fast-forward-only update, installs dependencies, and starts the bot.
6. Start the server. Slash commands are registered automatically when the bot connects; a separate deploy:commands step is not normally required.
7. Confirm logs show successful login and command registration.

## Data preservation
- The repository ignores .env, node_modules/, data/, and SQLite database files.
- Keep DATABASE_PATH pointed to persistent Pterodactyl storage.
- Do not delete data/, bot.sqlite, or SQLite WAL/SHM files when updating.
- The startup command deliberately uses git pull --ff-only, not git reset --hard, so it does not force-discard local changes.
- Keep Pterodactyl's normal persistent server directory enabled.

## Troubleshooting
- If git pull fails because this directory is not a Git clone, clone the repository into the server directory first; do not paste the repository files over an existing database directory.
- If npm install fails, inspect the full install log; better-sqlite3 requires a compatible Node.js runtime and native build support.
- If the bot logs a missing configuration error, add the named variable in Pterodactyl and restart.
- If login fails, verify DISCORD_TOKEN and outbound network access.
- The bot requires Server Members Intent and Message Content Intent in the Discord Developer Portal. Invite it with bot and applications.commands scopes and only the permissions required for enabled features.
